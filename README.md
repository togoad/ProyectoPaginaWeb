# Los Naranjos · v0.0

Primera versión de la web de Los Naranjos. Es una página estática hecha con HTML, CSS y JavaScript, sin dependencias ni instalación.

## Archivos

- `index.html`: contenido y estructura de la página.
- `styles.css`: diseño adaptable a móvil y escritorio.
- `script.js`: menú móvil y año automático del pie de página.
- `assets/logo-los-naranjos.png`: logo facilitado para el proyecto.

## Ver la página

Abre `index.html` en un navegador. También puedes publicar el contenido de esta carpeta en un repositorio de GitHub. Para GitHub Pages, copia estos archivos a la raíz del repositorio o configura la publicación para que use esta carpeta.

## Contenido pendiente

Los textos visibles como “Añadir dirección del pub”, “Sabor por añadir” y “Fecha por confirmar” son marcadores para completar cuando estén disponibles la carta, los sabores, los eventos, el horario y los datos de contacto reales. No hay formulario ni envío de mensajes configurado.
